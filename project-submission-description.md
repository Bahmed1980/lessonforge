# LessonForge — Hackathon Submission Description

---

## 🎯 Project Title
**LessonForge: AI-Powered Lesson Pack Generator for Teachers**

---

## 🧩 Problem Statement

Teachers — especially in under-resourced schools across Africa — spend hours every week creating lesson plans, explanations, quizzes, and class activities. This time is taken away from actual teaching. There are very few free, instant tools that generate complete, curriculum-aligned teaching materials on demand.

LessonForge solves this by turning a teacher's topic and grade level into a full, ready-to-teach lesson pack in under 60 seconds.

---

## 💡 What It Does

LessonForge is a web application where a teacher enters:
- A topic (e.g. "Photosynthesis" or "The Water Cycle")
- A grade level (e.g. "JSS2" or "Primary 5")

The app then generates a complete lesson pack including:
1. A structured **lesson plan** with learning objectives and duration
2. A **story-based explanation** written in simple, relatable language
3. **5 quiz questions** with answers
4. A **hands-on class activity** idea

The teacher can copy or download the full pack instantly — no account required.

---

## 🛠️ Technologies Used

- **GitHub Copilot** (in VS Code) — used throughout development to write and refine the app code
- **Microsoft Foundry IQ** — powers grounded knowledge retrieval to reduce hallucinations and ensure lesson content is accurate and curriculum-relevant
- **HTML / CSS / JavaScript** — lightweight frontend, works in any browser
- **GitHub Pages** — free hosting so the app is accessible to teachers anywhere

---

## 🏗️ How Microsoft IQ Is Used

**Foundry IQ** serves as the intelligence backbone of LessonForge. When a teacher submits a topic:

1. The app sends the topic + grade level to Foundry IQ
2. Foundry IQ retrieves relevant, grounded knowledge from connected educational sources
3. The retrieved knowledge is used to generate accurate, cited lesson content
4. This prevents the AI from making up facts — critical for educational content

This use of Foundry IQ ensures LessonForge is not just creative, but **reliable and safe** for classroom use.

---

## 🌍 Impact & Why This Matters

- Saves teachers **2–5 hours per week** on lesson preparation
- Designed for **Nigerian and African school systems** (JSS/SSS grade levels supported)
- Works in the browser — **no download or installation needed**
- **Mobile-friendly** for teachers without laptops
- Built with **accessibility-first** design principles (high contrast, readable fonts, screen reader support)
- Directly addresses the UN Sustainable Development Goal **SDG 4: Quality Education**
